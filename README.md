# Sauron — installeurs

Extension Adobe Premiere Pro pour monter pendant qu'on tourne : les rushs
enregistrés en direct arrivent tout seuls au bout d'une séquence, puis sont
remplacés par les fichiers 4K de la caméra une fois le montage fini.

Ce dépôt ne contient que les **installeurs** publiés à chaque version : le
panneau Sauron y cherche ses mises à jour. Le code n'est pas ici.

- Windows : `Sauron-Setup.exe`
- Mac : dans le Terminal,
  `curl -fsSL https://github.com/Splainte/Sauron-releases/releases/latest/download/install-macos.sh | bash`

Dernière version : onglet [Releases](../../releases/latest).
